## Vision

### Reframe
Open-source project chasing an "aha!" moment, not a commercial product competing with
Google. "OpenClaw on mobile": an open, agent-native OS where agents drive the apps out
of the box. Success = a jaw-dropping, forkable demo, not market share.

**v1 vs north star (so the vision doesn't overclaim).** v1 delivers the *aha of an
agent-native OS* via a normal Android app on a stock OS (built app-first per the eng
review). The full custom AOSP OS and fully-local/offline model are the **north star**,
not what the first demo ships. The prose below describes the north star; the "v1
Definition" and "Accepted Scope" sections are what actually gets built now.

### Differentiation (the axis Google structurally won't touch)
Lead with **open + model-agnostic + user-owned**. That is the moat: Gemini Intelligence
is closed, Gemini-only, and cloud-tied, and Google will not ship an open, BYO-model,
you-own-your-data version. "Agents-as-primary-actor" is the **demonstration medium**, not
the differentiator (Gemini already ships agent-drives-apps, so leaning on it invites the
"Google already does this" reaction). The visible, copy-proof flex is openness made
tangible: swap the model on screen, read the agent's mind, fork the whole thing.

### 10x Check (north star)
An open OS where a team of agents visibly orchestrates your apps, fully transparent (the
phone narrates itself), model-agnostic down to fully-local/offline. A demo no closed
assistant can show. v1 demonstrates a believable slice of this; it does not claim to be
the finished OS.

## v1 Definition (what the demo actually is)

- **Host:** a normal Android app on a stock (Integrity-passing) emulator/phone, driving
  apps via Accessibility + intents. Full AOSP build is the north-star track, not v1.
- **Target apps for the demo:** 2-3 open / installed / web apps that cooperate with
  Accessibility (e.g., an open maps app, a messaging app, a calendar). Integrity-gated
  banking is explicitly out.
- **Single-agent loop (the foundation everything gates on):** perceive app state (a11y
  tree) -> decide the next action (model) -> act (tap/type/intent) -> narrate -> repeat,
  with the out-of-model safety gate on high-side-effect actions.
- **Model-agnostic mechanism:** one `ModelProvider` interface behind the dual-auth seam.
  Adapters for Claude-subscription (OAuth) and Anthropic API key ship in v1; the same
  interface is where a local backend plugs in later. BYO-key is first-class.
- **Demo script (canonical):** user types an intent that spans 2-3 apps (e.g., "find a
  coffee place near the office and text it to the group"); the agent perceives, plans,
  and acts across the apps; the **narration feed** shows each perception/plan/action
  live; the user taps a **visible provider-swap** toggle mid-demo to prove the model is
  swappable and yours.
- **Forkability bar:** **Apache-2.0** (chosen) + a README + a runnable demo (one command
  to launch on the emulator). A forker gets a working agent loop out of the box.
- **Hardening (from CEO review):** the narration feed MUST redact credentials, API keys,
  and on-screen secrets (it is a live public display of agent activity). The gated
  multi-agent coordinator needs a partial-result/merge policy (1A abort+handoff
  generalized to N parallel sub-agents) and an N-times token-cost budget.

## Scope Decisions

| # | Proposal | Effort | Decision | Reasoning |
|---|----------|--------|----------|-----------|
| 1 | Strategic altitude: full OS / OS-like, open, aha-focused | XL | ACCEPTED (user) | The OS is the north star; v1 delivers the aha via an app, app-first per eng review |
| 2 | Single-agent perceive-decide-act-narrate loop | M | ACCEPTED | The foundation; everything else gates on it |
| 3 | Live agent-activity narration feed | S | ACCEPTED | Highest aha-per-effort; makes autonomy legible; dodges Gemini-redundancy |
| 4 | Visible on-screen provider swap (open-only moment) | S | ACCEPTED | Guarantees ONE visible, un-gated openness moment so the demo can't collapse to "Gemini but open" |
| 5 | Multi-agent orchestration (coordinator + parallel sub-agents) | M | ACCEPTED (gated) | The defining OpenClaw aha; gated on the single-agent loop landing first |
| 6 | Fully-local/offline model backend | M+eval | DEFERRED | Headline v1.1 differentiator; plugs into the same ModelProvider seam; model-quality is its own research |

## Accepted Scope (added to / confirmed in this plan)
- Single-agent perceive-decide-act-narrate loop (the foundation).
- Live agent-activity narration feed in Milestone 0.
- Visible on-screen provider-swap toggle in Milestone 0 (the guaranteed open-only moment).
- Multi-agent orchestration as a gated M0 stretch goal (after the single-agent loop is solid).
- Positioning: lead with open + model-agnostic + user-owned; agents-as-actor is the medium.
- Demo scoped to open / installed / web apps driven out of the box (not Integrity-gated banking).
- Forkability bar: OSI license + README + one-command runnable demo.
